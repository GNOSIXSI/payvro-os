# Marca PAYVRO

Archivos oficiales de la marca PAYVRO (Nudo Geométrico). Se usan tal cual: no se redibujan, no se recolorean y no se deforman.

| Archivo | Uso |
|---|---|
| `payvro-logo-claro.svg` | Logo horizontal sobre fondo claro |
| `payvro-logo-oscuro.svg` | Logo horizontal sobre fondo oscuro |
| `payvro-logo-monocromo.svg` | Una tinta |
| `payvro-isotipo-color.svg`, `-blanco.svg`, `-tinta.svg` | Nudo solo |
| `payvro-wordmark.svg` | Solo la palabra |
| `payvro-favicon.svg`, `payvro-app-icon-*.svg` | Icono del sitio y de la app |

Colores: tinta `#142B3B`, blanco cálido `#F5F3EC`, petróleo `#076B76`. Acentos del nudo: `#00B8B2`, `#EF006D`, `#FFC400`, `#FF7900`.
Tipografías: Noto Sans Display (títulos) y Noto Sans (texto).
