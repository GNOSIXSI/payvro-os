# PAYVRO · Ajustes para construir la interfaz

**v1 · 14 de noviembre de 2026 · 34 ajustes · revisado por el gobernador.** La QA visual se hace sobre la app construida, no sobre el prototipo. Referencia para Next.js + Tailwind + shadcn/Radix, no autorización de publicación, merge ni despliegue.

## Alcance y precedencia

Revisión estática, **sin navegador ni agy**, de `diseno/README.md` y las 1,153 líneas de `diseno/payvro-pantallas-ux.html` (189,789 bytes). Se leyeron también `2026-11-14-founders.md` y `respuestas-fable-diseno-1.md`, `-2.md` y `-3.md`, ubicados un nivel arriba de `diseno/`. Las referencias `HTML:L…` apuntan al HTML descargado, sin modificarlo.

Mandato: decisiones de fundadores > respuestas del equipo cuando no las contradicen > README/prototipo. En particular, **«hasta 5 días hábiles» sustituye «5–7 días»**, y **FSL / código disponible sustituye código abierto**. Gratis incluye Membresía; Checkout queda en Business. No se reabren esas decisiones.

P1 = corregir antes de exponer el flujo correspondiente. P2 = requisito de integración o accesibilidad de la primera interfaz real. P3 = cierre documental/pulido. La lista distingue choques observados de precauciones de migración; no son 34 fallos de un producto implementado. No se acredita cumplimiento AA completo con esta lectura.

## Qué se conserva y qué falta medir

- Se conserva la identidad Nudo Geométrico, las familias tipográficas, tokens principales, es-MX, seis estados de cobro, estados con texto/icono, DEMO visible, webhook como aviso, y OS sin Plan con Equipo incluido.
- Medido aquí por fórmula WCAG sobre hex del código: gris 7.15:1, espera 8.37:1, verificado 7.03:1; petróleo sobre papel 5.61:1. No se cambiaron colores.
- **No medido:** layout renderizado, foco efectivo, lector de pantalla, contraste de composiciones/transparencias, gestos móviles ni flujos del backend. No se abrió navegador y no se enviaron capturas a agy.
